A few years ago, I was a co-organiser and then organiser of the PHP South Wales user group.

The events stopped after the COVID pandemic, and the website has been unmaintained and offline for some time.

I have the website data and source code, and plan on rebuilding it with Sculpin and hosting it on my home server - the same as this website.

There are no future events planned, but I think it would be nice to get the website back online as a record of the events, speakers and talks we had.

If you want to follow my progress, [here is the Git repository](https://git.oliverdavies.uk/opdavies/phpsouthwales.uk) I'll be working in.
