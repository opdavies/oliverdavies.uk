There are a lot of [open issues on Drupal.org][0] that have the "Needs tests" label.

These could be maintainers leaving themselves reminders to add tests once they've finished spiking out the first version of their code, or someone contributing to project but needs an accompanying test to ensure the feature works or that a bug is fixed (and will stay fixed).

There are currently 3,711 issues across all projects and 2,030 in Drupal core.

If one of those is your issue or module, I can write the tests you need.

After my [first podcast episode with Mark Conroy][2], I did this for [the Content Access by Path module][1], which now has tests and automated checks with GitLab CI - so they will be run for every future merge request.

You can see me writing them on [a previous live stream][4].

If you need tests written or help writing them yourself, reply and get in touch.

If you want to [sponsor my contribution time][3], you'll also get contribution credit for any issues or merge requests I work on during that time and, whilst it's been a while since my last live stream, you'd also be mentioned there as I work on these issues.

I have around a day a week available for sponsored contribution time.

If you're interested, reply and let's get it arranged.
